# Test Policía Local · Comunitat Valenciana

Web estática para practicar el cuestionario tipo test de Agente de Policía Local de la Comunitat Valenciana (temario del Decreto 179/2021).

- `index.html`: la web (HTML + CSS + JavaScript, sin dependencias).
- `data/temas.js`: lista de los 40 temas.
- `data/temaXX.js`: banco de preguntas de cada tema (100 por tema).
- `validar.js`: comprobación del banco. Ejecutar `node validar.js` antes de publicar.

Publicación gratuita con GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
